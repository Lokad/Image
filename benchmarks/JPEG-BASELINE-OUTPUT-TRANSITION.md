**Not accepted; the exact qualified code, embedded tests and actual package are
restored.** Shared entropy output and direct dequantization establish a useful
sparse-CMYK gain, but two material companion regressions prevent acceptance.
Passing native parity alone does not justify those regressions.

The independent sparse confirmation is 378.98/FFmpeg419.49 µs, upper .917;
equivalent fresh contexts give 355.33/755.39 µs, upper .502. Both pass with

increment; no clock or stage sums are substituted. All 12 actuals and native
brackets remain. Thirteen affected candidate controls pass their native gates,
but qualification stops at the demonstrated regressions. No favorable repeat.

The first correct composite destination implementation was 5.65% slower in a
controlled comparison. Its actual generated code repeatedly copied 40-byte state.
A mutable by-reference form failed safe C# lifetime checks before timing; no
unsafe workaround followed. Individual scoped numeric spans then achieved the
sparse gain above. A first attribution using the preserved composite build's
16-byte coefficient destination restores RGB420 to 713.14/FFmpeg1087.76 µs,
upper .667. Representation, arguments and store code all differ; this does not
prove any one instruction is the sole cause.

normal/scalar/AVX512-off/AVX2-off modes on Windows/Linux. These include exact DC,
modular AC, post-product support, dense/low-support/scan-order inverse pixels,

owners. No new heap owner, retained scratch or admission mechanism is introduced.
Main allocation stays unchanged; physical/native/JIT-stack peaks are unmeasured.
Broad and actual-package qualification were not run for either candidate.
Byte-identical restoration reuses the accepted 6,600 checks per OS and package
