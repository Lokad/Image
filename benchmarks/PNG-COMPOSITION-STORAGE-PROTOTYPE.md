**Promising; unpromoted.** Canonical source, qualified DLLs and the actual package
remain unchanged. An isolated prototype lets the existing pool retain four exact-
size arrays under the same 4 MiB byte ceiling and gives nearest resize the existing
complete-overwrite owner policy. No general cache, new public API, altered pixel
arithmetic or aliasing of live outputs. Root-governed calls bypass idle storage;
refusal remains terminal and charges/cleanup/lifetimes remain explicit.
