widths. One writer consumes these prepared representations directly, removing
duplicate classification/base arithmetic and separate width-array reads. It adds
a small preparation pass; stored blocks may prepare fields they never emit.

allowance, all capacities, retained storage and cleanup remain unchanged. Peaks
were not remeasured or inferred from GC or code size.
