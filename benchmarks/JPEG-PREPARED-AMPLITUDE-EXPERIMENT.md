# JPEG prepared-amplitude experiment

The bounded JHC497 experiment is unselected. Preparing small signed amplitudes
in the existing eight-bit Huffman lookup does not establish a reliable complete
decode gain. This stops the implementation, without banning revised architectures.

The first representation doubled primary-table capacity and failed 38 unchanged
public admission controls; it was not timed. Two subsequent versions use the
existing 512-byte table's spare nibble for ±1…±7, covering 93.28% of AC symbols on
the frozen RGB control. Both pass 400 internal and 375 public checks per normal/
scalar mode on Windows and Linux, including unchanged exact-admission checks.

Raw and reference-normalized confidence overlaps in both views: no causal gain,

Table preparation, ownership and output disposal remain timed.
