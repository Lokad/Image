# Borrowed JPEG table-view study

JTV531/JHP532 is unselected. Two correct representations have unpromising
complete-operation screens. Qualified sources, main/embedded modules and public
bindings are restored byte for byte on Windows/Linux; the actual package and
all 125 displayed costs are unchanged.

GC stays 10,088 / 4,520 B/op. These shorts establish no causal gain, regression
or equivalence. No independent confirmation, favorable repeat, workload expansion
or broad/package qualification follows. This is an implementation result, without
a permanent ban on table preparation or materially revised architectures.

A borrows the existing 256/1,024-entry tables once at fused/plain reader entry.
The actual JIT retains the primary bounds check and grows its local frame from
8 to 24 bytes, versus the original 816-byte routine. B keeps only the hot primary
view live, makes its eight-bit index explicit and leaves long lookup with the
owner. It removes the primary bounds check but retains the larger frame and
unpromising costs. Static load/check removal alone does not establish CPU savings.

Constructor storage/admission is unchanged. Full-source projections reconstruct
the qualified original; long-code/full-field guards, bit arithmetic, refills,
publication, grammar, failure boundaries and every poll remain. The narrowed
index is exact for every UInt64 cache because a logical right shift by 56 lies
in 0..255. No extra table, heap capacity, owner, cache, session or retained state.
Admitted/physical/native peaks were not remeasured or inferred from GC.

Each stage passes **401 internal / 375 public checks per normal/scalar mode on
each OS**, including actual block/prefix, phase, signed/category, partial-write,
cursor, stuffing/tail, cancellation and ownership controls. Two selected existing
public sync/async controls capture the actual production JIT. One immutable
core/embedded build per stage/OS; no public/harness/native/selector/fixture build.
Exact restoration reuses 5,875-check and same-actual-package qualification without
broad/package/restore rebuilds. Published packages remain unchanged.

The frozen RGB444 and sparse Adobe CMYK inputs/settings, complete decoding,
preparation/transform/packing, independently owned output/disposal, native
contexts, pixel/alpha/source/owner gates and idle-v2 guards remain. One CPU;
native brackets surround every screen. Current
[entropy attribution](JPEG-CURRENT-ENTROPY-ATTRIBUTION.md) remains source-valid
after restoration; instrumented elapsed is not timing evidence.
